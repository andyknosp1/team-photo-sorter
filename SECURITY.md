# Security policy

Please **don't** report security problems in public issues.

Report them privately through GitHub: **Security → Report a vulnerability** on
this repository. Include what you found, how to reproduce it, and what an
attacker could get, such as decrypting a site without the password or learning
names from file names.

You'll get a reply within a week. Fixes are released as a new version with a
note in [CHANGELOG.md](CHANGELOG.md).

What the site does and doesn't protect is described in
[docs/security.md](docs/security.md). Limits listed there, such as one shared
password or offline guessing of weak passwords, are known design limits rather
than vulnerabilities, but ideas to improve them are welcome as regular issues.
